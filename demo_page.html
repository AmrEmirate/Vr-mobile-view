VR Mobile Side Test Station

Halaman Uji Coba Pemutar Video & Fitur SBS VR

🚀 Panduan Uji Coba Ekstensi

  1. Instal Ekstensi: Buka menu Extensions di browser (Kiwi / Lemur / Chrome / Edge), aktifkan Developer Mode, lalu pilih Load Unpacked dan arahkan ke folder ini.
  2. Aktifkan Mode VR: Tekan ikon ekstensi VR Mobile Side di toolbar, atau gunakan tombol Alt + V.
  3. Kalibrasi Layar (Control HUD): Sesuaikan Zoom, IPD, Kecerahan, atau aktifkan mode Curved IMAX & Gyroscope.
  4. Siap Tonton: Pasang HP ke dalam headset VR Box / Google Cardboard dan nikmati bioskop virtual pribadi Anda.
